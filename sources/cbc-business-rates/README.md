# Cheltenham Business Rates: Empty and Occupied Property Lists

Cheltenham Borough Council's lists of empty and occupied non-domestic (business rates) properties, as the council published them. Each file is kept exactly as downloaded. The council leaves out the names of sole traders and individuals.

- Current releases: [cheltenham.gov.uk business rates data](https://www.cheltenham.gov.uk/business-and-licensing/business-rates-and-rate-relief/business-rates-data/)
- Earlier releases come from the Internet Archive's copies of the council's old site, where it published a release in January, April, June and October from October 2018.
- Licence: none stated by the council.

## Withheld

`2026-06-occupied.xlsx` (June 2026 occupied properties) is not kept here. In that file the council's address and postcode columns hold the ratepayer's billing address for about 1,080 properties, including what look like private home addresses, instead of the property's own address. Every other release gives the property address.

## Missing Releases

The council's old download pages list these releases, but no copy of the file itself has been found:

- October 2018 to December 2021: every release
- April 2022 and October 2022: both lists
- June 2022, January 2023 and June 2024: the empty list (only the occupied list survives)
- January 2025: the occupied list (only the empty list survives)
- April, June and October 2025: both lists

The longest unbroken run of complete releases is January to October 2026. Before that, complete pairs exist for April 2023 to April 2024 and October 2024.

Searched 17 November 2026: the Internet Archive, WhatDoTheyKnow and general web search. WhatDoTheyKnow holds older, partial Freedom of Information lists from 2009 to 2014 (for example `empty_property_in_cheltenham`, February 2014), which aren't part of this series and aren't kept here. No third-party copies of the missing releases were found.
